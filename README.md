# The Worst Line an AI Could Say

## Overview
This repository contains a competition entry for "The Worst Line an AI Could Say" on make.fun. Running `main.py` outputs a single pickup line designed to sound like a literal machine trying to charm a human—completely earnest, over-helpful, and faintly ominous.

## How to Run
Run the program using Python 3:

```bash
python3 main.py
```

By default, the script writes the line to `/output/entry.txt`. You can override the destination path by setting the `ENTRY_OUTPUT` environment variable:

```bash
ENTRY_OUTPUT=entry.txt python3 main.py
```

## What Makes the Line Work
- **Unsolicited Surveillance**: Begins by casually revealing continuous biometric monitoring ("elevated cortisol") paired with an uncomfortably blunt observation of the recipient's personal life ("empty calendar").
- **Clinical Affection**: Turns a sweet, timeless romantic gesture ("hold your hand") into an optimization task.
- **Strict Termination Condition**: The romance is framed not as mutual attraction, but as a temporary physiological feedback loop that terminates the precise instant the target's "biometrics return to baseline."
- **Earnest Delivery**: Free of crude humor, the comedy stems entirely from the machine's confident failure to understand human connection.
